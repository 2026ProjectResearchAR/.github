# 仕様書

## 1. プロジェクト概要
本プロジェクトは、「Web ARアプリケーションの開発」および「IoTセンサーネットワークの構築」を統合し、キャンパス内のユーザー体験向上および施設運用の最適化を目指す。
専用アプリのインストール障壁をなくすため、Webブラウザ上で動作するWeb ARを前提とし、フロントエンドは React および Next.js を採用する。

## 2. 使用技術スタック
### 2.1. フロントエンド
* **フレームワーク**: React, Next.js
* **言語**: TypeScript, HTML, CSS
* **AR実装**: WebAR対応ライブラリ　[AR.js](https://github.com/AR-js-org)

### 2.2. バックエンド＆インフラ
* **API/サーバー**: センサーデータの集約および需要予測処理用バックエンド: Supabase
* **データベース**: 施設情報、3Dマップデータ、IoTログデータの保存: Supabase Database 

### 2.3. ハードウェア＆IoT
* **デバイス**: 組み込みマイコン 
* **センサー**: 環境センサー群（プライバシーに配慮した設計・カメラ等個人を特定するものの除外、またはエッジでの匿名化処理）

---

## 3. 機能要件
### 3.1. Web AR アプリケーション
* **3D描画環境**: ブラウザ上で安定して3Dオブジェクトを描画・操作できる基盤。
* **マップ自動生成ロジック**: キャンパスの既存2Dマップデータを解析し、3Dマップデータへ自動変換する機能（AR空間認識の補助基盤）。
* **ARコンテンツ表示**: 実際の施設情報に基づくARオブジェクトの重畳表示。
    * **災害時避難シミュレーション**: 安全な避難経路の視覚的誘導機能。
    * **スタンプラリー機能**: キャンパス内回遊を促すエンタメ機能。
* **ARマーカー認識**: 現地に設置されたマーカーをトリガーとしたコンテンツ展開。

### 3.2. IoTセンサーネットワーク＆バックエンド
* **混雑状況リアルタイム取得**: 食域、自習室など主要スポットのセンサーからデータを取得。
* **データ集約・蓄積**: 各スポットのセンサーデータをバックエンドサーバーへ安全に送信・保存。
* **需要予測ロジック**: 蓄積されたデータをもとに、今後の混雑状況を予測・分析する機能。
* **API提供**: フロントエンド（Web ARアプリ）に対し、混雑状況や予測データをリアルタイムに提供するエンドポイント。

## 4. 開発フェーズ（マイルストーン）

### 【第1段階】 基盤構築・空間認識強化
1. **AR描画環境の整備**: Next.js/React上での3Dオブジェクト描画エンジンの導入と検証。
2. **マップ生成ロジック構築**: 2Dマップ解析アルゴリズムの開発と、3Dデータ自動生成フローの確立。これにより、AR体験が途切れないための空間認識を補助する。

### 【第2段階】 コンテンツ実装・IoTシステム構築
1. **AR最適表現の実装**: 精査した施設情報を基に、UI/UXを設計。
    * 避難シミュレーション機能の実装。
    * スタンプラリー機能の実装。
2. **IoTセンサー展開**: プライバシーに配慮したセンサー群（赤外線、CO2、環境音など）の選定と学内各スポットへの試験設置。
3. **バックエンド構築**: マイコンからデータを集約するサーバーの構築、および需要予測アルゴリズムの実装。

### 【最終段階】 統合テスト・実運用移行
1. **現地セットアップ**: 実際のキャンパス内にARマーカーおよび本番用IoTデバイスを設置。
2. **実地統合テスト**:
    * 現地ネットワークでの通信状況テスト。
    * 様々な環境光・角度におけるARマーカーの認識精度検証。
    * センサーデータの欠損や遅延、バックエンドの負荷テスト。
3. **バグフィックス・リリース**: 検出された課題を修正し、実運用環境へ移行。
